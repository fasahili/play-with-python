# 🐍 Python Examples Project

This repository contains a collection of simple and practical Python programs.  
Each script demonstrates a specific Python concept or task, and is stored in its own file for clarity.

---

## Project Structure

```bash
python-examples/
│
├── math_operations/
│   ├── prime_number.py              # Check if a number is prime
│   ├── factorial.py                 # Calculate factorial of a number
│   ├── fibonacci.py                 # Print Fibonacci sequence
│
├── list_operations/
│   ├── remove_duplicates.py         # Remove duplicates from a list
│   ├── list_del_remove_pop.py       # Difference between del, remove, and pop
│   ├── merge_inverse_lists.py       # Merge and reverse two lists
│   ├── list_slicing.py              # Demonstrate list slicing
│   ├── flatten_list.py              # Flatten a nested list
│
├── dictionary_operations/
│   ├── merge_dicts.py               # Merge two dictionaries
│   ├── lists_to_dict.py             # Convert two lists into a dictionary
│   ├── delete_dict_element.py       # Delete key from dictionary if it exists
│
├── file_operations/
│   ├── read_write_file.py           # Read and write to a file
│   ├── append_file.py               # Append content to a file
│
├── string_operations/
│   ├── remove_punctuations.py       # Remove punctuation from a string
│   ├── sort_words.py                # Sort words alphabetically
│
├── misc/
│   ├── class_name.py                # Get class name of an instance
│   ├── random_number.py             # Generate a random number
│   ├── shuffle_deck.py              # Shuffle a deck of cards
│   ├── builtin_ops.py               # Use built-in operators on dict, list, tuple
│   ├── user_input.py                # Read user input and print it
│   ├── memory_diff.py               # Show memory address difference between list objects
│
```

## Requirements

-   Python 3.6 or higher
-   No external libraries are required (except for optional examples like `numpy` or `itertools` which are in the standard library)
